A newer skill

AI coding agents, adopted in 2025 and put to work

Most of the work on this page predates AI coding agents: the arcade edition, the Vision Pro core, the interface overhaul and the Switch systems. I started using agents in late 2025, partway through building the progression system, and have spent the year since getting good at it.

I work with them in a disciplined way. I write the spec and the plan, direct the agents, review what they produce, and check the result myself in the editor and in the headset. Core logic gets its tests first, and a feature ends with tests that pin its behaviour. Building on automation tools my teammates had set up, I wrote the project's playbook for driving the editor with agents, added new scenarios to the menu-navigation test harness, and built my own verification probes and a test runner that works with the editor closed.

In 2026 that meant about twice the output of the year before, including features I owned from the database to the last polish pass on the interface.
